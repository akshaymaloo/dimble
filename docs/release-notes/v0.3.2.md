# Dimble 0.3.2

Changed:

- Pliss is now Dimble. On its first launch after the update, the app renames itself from Pliss.app (or Pelmet.app) to Dimble.app and opens again. Settings, permissions and launch at login carry over.
- The app icon is a D now, same dots.
- Logs are now in ~/Library/Logs/Dimble/dimble.log, and your old logs move there too.
- Homebrew: the cask is `dimble` now. Run `brew trust --cask fif7y/tap/dimble && brew migrate --cask pelmet` once. If an update already renamed the app, use `brew reinstall --cask fif7y/tap/dimble` instead.

Fixed:

- Changing "Show hidden icons in" while the hidden icons are out now puts them away first, and the next click opens them in the new place. Before, an open row could turn into a grid, or the icons stayed in the menu bar (#26, thanks @cpierce).
