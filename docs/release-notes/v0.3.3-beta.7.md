# Dimble 0.3.3-beta.7

Seventh beta of 0.3.3, on the beta channel only (Settings › About › "Get beta releases").

Fixed:

- Without Screen Recording, a display that shows all its icons now opens its panel or row on the first chevron click. It used to widen the menu bar, and only the third click opened the panel. Closing the panel puts that display's hidden icons back on its bar (#96, thanks @juanfcocontreras).
