# Dimble 0.3.3-beta.6

Sixth beta of 0.3.3, on the beta channel only (Settings › About › "Get beta releases").

Changed:

- A display that shows all its icons now has its own "Show hidden icons in" in Settings › Displays. It picks where a chevron click there opens Always Hidden: the menu bar, a panel or a row. Before, it always followed the Panel tab (#96, thanks @juanfcocontreras).
- "Reveal in" in Settings › Displays is now "Show hidden icons in", the same name as in the menu and the Panel tab.
